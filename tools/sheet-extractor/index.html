🖼️ Sheet Extractor

Upload a flat-lay reference image — a moodboard, sprite sheet, or a photographed/scanned sheet of stickers — and cut out every visually distinct object into its own real, transparent PNG.

1. Upload a reference image

Click to choose a file, or drag and drop it here.

PNG or JPEG. Works best on a clean, roughly-uniform background with real gaps between objects.

2. Options defaults work well for most sheets — only adjust if results look off

24
How different a pixel must be from the background to count as part of an object. Lower = catches subtle/near-background colors; higher = more tolerant of background texture.
8%
Extra room left around each object's own tight bounding box, so nothing is cropped flush.
0.015%
Objects smaller than this fraction of the whole image are discarded as noise/dust specks.
2
Bridges tiny anti-aliasing/compression gaps so one object isn't split into pieces. Never affects what's actually cropped.
Output files are named <prefix>-001.png, -002.png, etc.
Use this if the corners aren't representative of the true background.

3. Results

Color-distance / connected-component segmentation, not semantic object detection — it will merge two objects that visually touch with no gap, and it needs a reasonably clean background. See README.md for the full, verified account of what this was tested against and its real, disclosed limitations. Runs entirely in your browser — nothing is uploaded anywhere.
