🖼️ Sheet Extractor

Cut every distinct object out of a reference image into its own real, transparent PNG. Use Sheet for a moodboard or sticker flat-lay, or Scan for a photographed page of line art.

1. Upload a reference image

Click to choose a file, or drag and drop it here.

PNG or JPEG. Sheet mode wants a clean, roughly-uniform background with real gaps between objects. Scan mode wants a photo of a drawn page.

Drag on the picture to use only part of it.

2. Options defaults work well — only adjust if results look off

Mode
24
How different a pixel must be from the background to count as part of an object. Lower = catches subtle/near-background colors; higher = more tolerant of background texture.
18
How much darker than the paper around it a pixel must be to count as ink. Lower catches faint pencil; raise it to drop bleed-through from the previous page and paper texture.
3%
How far out to look when working out what "the paper right here" is. This is what lets one setting span a lit corner and a shaded one. Too small and thick strokes hollow out; too large and it behaves like a global threshold again.
1
Thickens the traced line before it's drawn. A pencil stroke photographed at an angle is often only a pixel or two of real darkness, which reads as thin and broken once redrawn.
Every cutout is drawn in this colour. None of the photo's own greys survive, so this is free to be anything.
8%
Extra room left around each object's own tight bounding box, so nothing is cropped flush.
0.015%
Objects smaller than this fraction of the whole image are discarded as noise/dust specks.
2
Bridges gaps so one object isn't split into pieces. Never affects what's actually cropped. Scan mode wants this much higher — it's what pulls separate pen strokes into one drawing, or letters into one word.
Output files are named <prefix>-001.png, -002.png, etc.
Use this if the corners aren't representative of the true background.

3. Results

What was traced Black is what counted as ink. If your drawing is broken up, lower Ink Sensitivity or raise Ink Weight; if the paper itself is showing up, raise Ink Sensitivity.

Pixel segmentation, not semantic object detection — either mode will merge two objects that visually touch with no gap. Sheet mode also needs a reasonably clean background; Scan mode reads local contrast instead, but does not dewarp a curved or angled page.
